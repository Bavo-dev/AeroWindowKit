# Changelog

## 1.1.0 — 2026-09-13

- Added configurable window resize handles
- Added minimum window size support
- Added left/right edge snapping
- Added top-edge maximize while dragging
- Added drag-to-restore for snapped and maximized windows
- Added optional PlayerPrefs layout persistence
- Added public `SnapLeft`, `SnapRight`, `SaveLayout`, `LoadLayout`, and `ResetSavedLayout` APIs
- Updated the one-click demo to showcase resize and snapping
- Expanded setup and usage documentation

## 1.0.0 — 2026-09-13

- Initial open-source release
- Draggable windows with Canvas clamping
- Focus / bring-to-front behavior
- Minimize-to-taskbar support
- Maximize and restore
- Hide or destroy on close
- One-click demo UI creator
