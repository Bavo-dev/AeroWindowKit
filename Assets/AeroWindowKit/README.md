# AeroWindowKit package

AeroWindowKit is a dependency-light desktop-style window manager for Unity uGUI.

## v1.1 features

- Drag + focus ordering
- Minimize to taskbar
- Maximize / restore
- Left/right edge snapping
- Top-edge maximize
- Configurable resize handles
- Minimum window size
- Optional PlayerPrefs layout persistence

For full setup instructions, see the repository README or `Documentation/GettingStarted.md`.
